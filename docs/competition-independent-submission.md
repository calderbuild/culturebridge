## 一、项目定位

中国数字文化出海面临三道障碍：**语言、声音、文化**。

| 障碍     | 现有方案                 | 结果             |
| -------- | ------------------------ | ---------------- |
| 语言     | GhostCut 等翻译工具      | 已成熟           |
| 声音     | DubbingX（上届大赛金奖） | 已成熟           |
| **文化** | **空白**                 | **本项目切入点** |

"臣妾做不到"被直译为 "I, your servant, cannot do it"，海外观众看不懂也感受不到原作的文化韵味。我们做的是**第三道障碍**——文化适配。

CultureBridge 是一个 AI 文化顾问引擎：输入任意中国文化文本内容（短剧剧本/网文章节/游戏对白/动漫台词等），通过多 Agent 协作 + 人工审核的结构化文化知识库，输出六件套：

1. 文化适配翻译（不是直译，是"翻译文化"）
2. 翻译决策报告（每个文化术语为什么这么翻）
3. 文化风险扫描（哪些表达在目标市场可能引发争议）
4. 改编建议（哪里需要本地化重写）
5. 文化注释（给海外读者的文化背景说明）
6. 多平台推广素材（TikTok / Instagram / YouTube / X 一键适配）

让每个出海团队都用得起"黑神话悟空"级别的文化把关能力，而不是只有大厂请得起的文化顾问。

## 三、技术架构

```
输入（中国文化文本 + 目标市场 + 内容类型）
  → Agent 0: 内容生成（可选，小白模式）
  → Agent 1: 文化元素扫描（DeepSeek，识别文化负载词）
  → Agent 2: 知识库匹配 + 风险评估（90+ 条文化映射）
  → Agent 3: 文化适配翻译（Claude Sonnet 4）
  → Agent 4: 审校（DeepSeek，回译验证 + 文化一致性检查）
  → Agent 5: 终稿 + 推广素材（Claude Sonnet 4）
  → 输出六件套
```

- **后端**：Python 3.10+ / FastAPI / SSE 流式进度
- **LLM**：DeepSeek V3 + Claude Sonnet 4（统一通过 OpenRouter）
- **文化知识库**：90 条人工审核映射，覆盖宫廷 / 武侠 / 修仙 / 都市四大题材
- **图片生成**：Gemini Imagen 4
- **多平台发布**：X / YouTube / TikTok / Instagram OAuth 集成
- **前端**：HTML + Tailwind 三步向导（选择→处理→发布）
- **部署**：Render 免费版（已上线）

### 核心壁垒：文化知识库

不是 LLM 自动生成，是人工审核的结构化条目。每条包含：

- `concept` 文化概念（如"臣妾"）
- `context` 出现场景
- `content_types` 适用内容形态
- `good_translations` 推荐译法（带文化注释）
- `bad_translations` 反面案例
- `principle` 翻译原则
- `cultural_note` 文化背景说明

跨内容形态通用——同一条映射在短剧 / 网文 / 游戏 / 动漫中均适用。这是 LLM 一次性提示工程无法替代的资产。

## 四、差异化定位

| 维度     | 通用翻译工具（GoogleTranslate / DeepL） | 影视字幕翻译（GhostCut） | CultureBridge                         |
| -------- | --------------------------------------- | ------------------------ | ------------------------------------- |
| 处理单位 | 句子                                    | 字幕行                   | 文化概念                              |
| 输出     | 译文                                    | 译文 + 时间码            | 译文 + 决策报告 + 文化注释 + 风险扫描 |
| 知识来源 | 通用语料                                | 字幕语料                 | 结构化文化知识库（人工审核）          |
| 适用场景 | 通用文本                                | 视频字幕                 | 中国文化内容出海全链路                |

上届金奖 DubbingX 解决了"配音"环节，本项目解决"内容适配"环节，二者互补不冲突。

## 七、独立参赛的优势与风险

**优势**：

- 决策链短，迭代快——产品方向不受公司审批节奏影响
- 知识产权清晰——后续无主体归属争议
- 评审视角友好——独立创业者 / 学生赛道符合赛事鼓励对象

**风险与应对**：

- **风险 1：缺企业背书** → 用真实 Beta 用户案例（短剧出海公司试用反馈）+ 部署上线演示替代
- **风险 2：技术展示需要算力** → 目前 Render 免费版可承载 Demo 演示，决赛若有更大压力测试需求再升级到付费 tier（成本可控）
- **风险 3：无团队** → 项目代码、知识库、商业方案全部已落地，可单人完成初赛 / 复赛答辩；决赛若需要可邀请短期合作者
