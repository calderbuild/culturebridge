## 一、项目背景：中国数字文化出海的"第三道障碍"

中国数字文化内容出海已经成为国家战略级议题。短剧月活全球 TOP3、网文海外用户超 2 亿、《黑神话：悟空》Steam 同时在线百万、原神在全球 180 个国家上线。**但中国内容真正被海外用户"看懂、看进、看上瘾"的比例仍然偏低**。

我们把内容出海的核心障碍拆成三道：

| 障碍                         | 现有方案                                | 状态             |
| ---------------------------- | --------------------------------------- | ---------------- |
| **语言**：字幕、文本翻译     | GhostCut 等 AI 字幕工具，日处理 10 万集 | 已成熟           |
| **声音**：AI 配音、口型      | DubbingX（上届"文创上海"大赛金奖）等    | 已成熟           |
| **文化**：典故、潜台词、语境 | 空白                                    | **本项目切入点** |

文化障碍最典型的失败案例：

- "臣妾做不到" 被直译为 "I, your servant, cannot do it" — 海外观众一头雾水
- 修仙小说里"渡劫" 被翻译成 "passing through tribulation" — 字面对但失去"逆天改命"的文化重量
- 武侠"江湖"被译为 "rivers and lakes" — 完全丢失"中国人想象中的灰色道义空间"
- 宫斗剧"本宫" 被翻译成 "I, the palace" — 不仅没有等级感，还制造笑点

这些不是翻译水平问题，是**翻译范式问题**：把"文化负载词"当作普通词来翻。

**CultureBridge 解决的就是这件事**：把翻译单位从"句子 / 字幕行"提升到"文化概念"。

## 二、产品定义：让中小出海团队用得起"黑神话悟空"级文化把关

CultureBridge 是面向中国数字文化内容出海的 **AI 文化适配引擎**。

### 输入

中国文化文本内容（短剧剧本 / 网文章节 / 游戏对白 / 动漫台词 / 有声书脚本）+ 目标市场（英语 / 日语 / 韩语 / 其他）+ 内容类型。

### 处理：6 Agent AI Pipeline

```
Agent 0：内容创作（可选，给小白模式）
  ↓
Agent 1：文化元素扫描（DeepSeek V3，识别文化负载词）
  ↓
Agent 2：知识库匹配 + 风险评估（90+ 条人工审核映射）
  ↓
Agent 3：文化适配翻译（Claude Sonnet 4，输出主译文）
  ↓
Agent 4：审校（DeepSeek，回译验证 + 一致性检查）
  ↓
Agent 5：终稿 + 多平台推广素材（Claude Sonnet 4）
```

### 输出"六件套"

1. **文化适配翻译**：不是直译，是"翻译文化"——保留文化重量
2. **翻译决策报告**：每个文化术语为什么这么翻、参考了哪条原则
3. **文化风险扫描**：哪些表达在目标市场可能引发宗教、政治、性别敏感
4. **改编建议**：哪些段落建议本地化重写而非翻译
5. **文化注释**：给海外读者的文化背景说明，可贴在剧本注释 / 网文页脚 / 游戏 wiki
6. **多平台推广素材**：TikTok / Instagram / YouTube / X 一键适配的标题、描述、hashtag

## 三、核心壁垒：文化知识库（人工审核，非 LLM 生成）

这是我们最重要的资产，也是最难被复制的部分。

### 不是 LLM 自动生成

每条映射都是人工查证、人工审核、人工注释。LLM 拿来直接生成的"文化映射"会出现：

- 错误归因（把"龙"等同于 dragon，但中文龙 ≠ 西方 dragon）
- 时代错乱（把网络梗误标为传统典故）
- 文化误读（把宫斗权术误读为爱情故事）

我们的库每条都解决具体翻译场景，跨内容形态通用。

### 库结构（每条字段）

```json
{
  "concept": "臣妾",
  "context": "嫔妃在皇帝/皇后面前自称",
  "content_types": ["palace_drama", "novel", "game"],
  "good_translations": [
    { "target": "en", "text": "Your humble consort", "note": "等级感保留" },
    {
      "target": "en",
      "text": "Your servant (used by imperial concubines)",
      "note": "需要注释"
    }
  ],
  "bad_translations": ["I, your servant", "Me, the imperial woman"],
  "principle": "嫔妃自称包含'等级 + 性别 + 朝代'三重信息，需要保留至少两层",
  "cultural_note": "中国后宫制度下，嫔妃地位低于皇后..."
}
```

### 当前规模（已入库，决赛前扩至 150+）

| 题材                                 | 当前条数 | 决赛前目标 |
| ------------------------------------ | -------- | ---------- |
| 宫廷（臣妾 / 本宫 / 御赐 / 凤袍 等） | 23       | 35         |
| 武侠（江湖 / 内力 / 轻功 / 武林 等） | 20       | 30         |
| 修仙 / 玄幻（渡劫 / 金丹 / 元婴 等） | 27       | 40         |
| 都市（相亲 / 彩礼 / 面子 / 关系 等） | 20       | 35         |
| 仙侠 / 奇幻新增                      | 0        | 10         |
| **合计**                             | **90**   | **150+**   |

### 跨内容形态通用

同一条"渡劫"映射，同时适用于：

- 修仙网文（番茄、起点）
- 修仙短剧（红果、迷雾剧场）
- 仙侠游戏（《原神》、《剑网 3》）
- 修仙动漫（《斗破苍穹》、《吞噬星空》）

一条映射，多场景复用——这是 LLM 一次性 prompt 无法替代的。

## 四、市场分析：被 GhostCut / DubbingX 教育过的"半熟"市场

### 市场容量

| 细分               | 体量                    | 数据来源              |
| ------------------ | ----------------------- | --------------------- |
| 海外短剧内购       | $20.58 亿，同比 +126%   | 点点数据 2026         |
| 网文海外活跃用户   | 2 亿，覆盖 200+ 国家    | 国家新闻出版署 2025   |
| 中国自研游戏海外收入 | $204.55 亿 / 年       | 伽马数据 / 音数协 2025 |
| 国漫出海           | 累计发行国创 100+ 部 / 约 1500 集 | 人民日报 2025 |

**总盘**：中国数字文化出海内容营收为数百亿美元级，其中文化本地化与审校支出（约占内容营收的个位数百分比）是 CultureBridge 的可寻址市场；字幕、配音工具已把出海赛道教育成熟，文化适配是下一个高增长卡点。

### 上届赛事验证（DubbingX 路径）

同一赛道的 AI 配音出海项目 **DubbingX** 就是文化出海的**前置环节**。DubbingX 解决了"声音"，市场反馈：

- 客户用了 DubbingX 之后，最大的下一个抱怨是"声音对了但意思没翻好"
- 翻译团队人力扛不动短剧的日 1 万行字幕节奏
- 大厂自建文化顾问团队成本太高（人均 30k+/月），中小团队用不起

CultureBridge 是 DubbingX 客户的**自然下一站**。

### 客户画像（已识别 3 类）

1. **短剧出海公司**（中文在线 / 九州文化 / 点众等）
   - 痛点：日产 5-10 部短剧，翻译质量直接影响完播率
   - 付费意愿：按部 ¥500-2000，单公司年消费 ¥50-200 万
2. **网文出海平台**（起点国际 / Webnovel / Webcomics 等）
   - 痛点：海外读者评论里"看不懂的中国梗"反复出现
   - 付费意愿：API 按字数计费，¥0.1-0.5/千字
3. **独立游戏 / 动漫团队**（中型工作室）
   - 痛点：本地化预算紧、文化顾问请不起
   - 付费意愿：项目制 ¥3-10 万 / 项目

### 竞品分析

| 维度     | 谷歌翻译 / DeepL | GhostCut        | CultureBridge                                    |
| -------- | ---------------- | --------------- | ------------------------------------------------ |
| 处理单位 | 句子             | 字幕行 + 时间码 | 文化概念                                         |
| 输出     | 译文             | 译文 + SRT      | 译文 + 决策报告 + 文化注释 + 风险扫描 + 推广素材 |
| 知识来源 | 通用语料         | 字幕语料        | 人工审核文化知识库                               |
| 文化把关 | 无               | 无              | 90+ 条结构化映射                                 |
| 适用场景 | 通用             | 视频字幕        | 全文本类内容                                     |

GhostCut / DubbingX 是**互补关系不是竞争关系**：他们做声画，我们做文化适配。

**国际赛道的替代品视角**：中国文化 IP 在海外用户心里真正的竞争对手，是韩流、日漫、Netflix 等他国文化 IP 已经很成熟的全球本地化能力。它们的内容一出海就自带精细文化落地，而中国内容常常输在"翻译失真"这一步。CultureBridge 要补的正是这块短板，让中国文化 IP 在全球心智竞争中不因翻译走样而掉队。这是本项目的国际化站位，也是区别于所有"翻译工具"竞品的根本差异。

### 盈亏平衡点与可持续性

- **固定成本**：一个精简团队（产品 + 内容审核 + 顾问）加知识库持续建设，年化约 ¥50-70 万。
- **盈亏平衡点**：约 30-40 个 Team 版付费客户（¥1,999/月）即可覆盖固定成本；对应上表 Q2 到 Q3 之间达到平衡。
- **可持续性**：LLM 边际成本极低（每千字 ¥0.08），跨过盈亏平衡点后每增加一个订阅客户几乎全额转化为毛利；知识库越用越准、越用越大，边际服务成本随规模下降，财务结构随时间改善而非恶化。

### 海外分发与版权合作渠道

CultureBridge 不自建海外分发渠道，而是**借船出海**，嵌进出海方已有的分发与版权链路：

1. **上游生态互补**：与 GhostCut（字幕）、配音出海工具生态互补，直接触达它们已有的短剧 / 网文出海客户，这些客户本就握有海外发行与版权合作渠道。
2. **平台级 API 接入**：为短剧 / 网文出海平台提供 API，文化审校嵌入它们既有的多语言发行流程，成为版权交易前的合规环节。
3. **本地化营销**：面向出海内容团队做 B2B 内容营销（案例、白皮书、真实译前译后对比），不做 C 端投放，获客成本低。

## 六、技术架构

### 总体设计

```
[前端]
 三步向导（HTML + Tailwind）
  ↓ FastAPI + SSE 流式进度
[后端]
 6 Agent Pipeline（Python 3.10+）
  ↓ OpenRouter 统一调用
[LLM 层]
 DeepSeek V3（中文理解强 / 成本低）：扫描 / 匹配 / 审校
 Claude Sonnet 4（多语言输出质量高）：翻译 / 终稿
  ↓
[知识库]
 90+ 条 JSON 映射 + 检索逻辑
[图片 / 视频]
 Gemini Imagen 4（推广素材插图）
[发布]
 X / YouTube / TikTok / Instagram 各平台推广素材适配生成（一键发布通道规划中）
```

### 容错设计

- **Scanner 和 Translator** 是关键 Agent，失败则终止任务
- **Matcher / Reviewer / Finalizer** 可降级，失败返回部分结果，不阻塞主流程
- SSE 流式输出：每个 Agent 实时回传进度，用户可视化看到处理过程

### 部署

- **当前**：Render 免费 tier，自动 push 部署
- **后续**：阿里云 / 腾讯云国内访问 + Vercel 海外访问的双线部署
