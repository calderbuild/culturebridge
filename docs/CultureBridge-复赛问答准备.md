# CultureBridge 复赛问答备战卡

复赛拿名次的真正战场在问答，不在 slide。官方建议 7 分钟路演 + 3 分钟提问，口播压到 6:40 后约有 3 分钟问答，问题不会多，每个都要答在点上。

**回答通用公式**：结论先行（一句话正面回答，不绕弯）→ 一个具体证据/数字 → 若是短板，主动给「已经在做的下一步」（不辩解、不过度承诺）。

**标注**：`[你定稿]` = 答案涉及你的真实决定/现状，我不能替你编，必须你本人核实后定稿。

## 壁垒类

**Q1「90 条知识库，别人用 GPT 三天就能仿一个，护城河在哪？」**
> 复制 90 条容易，复制「持续正确扩充到 500 条、跨题材复用、人工审核不出错」这套流程难。护城河是审核方法论和结构化字段设计这个流程资产，不是 90 这个数字。更关键的是下一步：当我们嵌进客户审校环节，每次采纳、拒绝、改写都反哺知识库，这个数据竞品拿不到，因为他们不在客户工作流里。

**Q2「知识库谁审核？标准是什么？怎么保证不出错？」** `[你定稿]`
> 结论先行：知识库不是让大模型自己生成的，每条人工查证。
> [你定稿：如实说明目前审核由谁做、参照什么依据，比如古汉语词典、权威字幕对照。别把「计划请的文化顾问」说成已经在审。] 决赛前引入古汉语/中国文化背景顾问做二审，是流程规划内的下一步。

## 技术类

**Q6「6 个 Agent 是不是过度设计？一个大模型加 prompt 不就行了？」**
> 单次让大模型现场翻一遍，做不到「扫描-匹配-翻译-审校-终稿」各自需要的独立容错。审校要做回译验证，本质需要第二次独立视角，塞进同一个 prompt 会被同一模型的盲点污染。拆分是为了让每一步能独立降级、独立换模型，不是为了显得复杂。

**Q7「LLM 会不会幻觉出错误的文化映射？出了政治/宗教/性别敏感问题怎么办？」**
> 这正是知识库要人工审核、而不是让 LLM 自由生成的原因。LLM 只负责识别「是不是文化负载词」，具体译法必须命中人工审核过的条目才采用；库外的表达会被标注为「风险待人工复核」，而不是硬翻。这是降级设计，不是让模型自由发挥。

**Q8「处理一段文本要多久？能撑住短剧公司日产几十集吗？」**
> 结论先行：一段 150 字左右的剧本，端到端约 4 到 5 分钟（实测两次分别是 262 秒和 290 秒），瓶颈不在我们服务器，在背后 LLM API 本身的响应时间。
> 目前是同步单任务处理，这个速度撑不住日产几十集的节奏。要支撑规模化，下一步是做批量异步队列 + 多任务并发调用，这是拿到真实客户后要优先补的工程能力，现在的优先级是先把翻译质量和知识库打磨对。
> 这也是为什么演示环节我用预录视频，不现场跑：不是产品不能跑，是 5 分钟等待不适合 10 分钟的路演节奏。

## 竞品类

**Q9「如果字节/腾讯或 DeepL 下场做文化知识库，你怎么办？」**
> 大厂有能力做，但没动力先做。文化知识库需要愿意为「江湖」「渡劫」这种词较真的团队，这对大厂是边际收益很低的脏活累活。等大厂反应过来，我们已经用真实客户数据把信任关系和数据壁垒建起来了。

**Q10「你说 GhostCut/配音出海是互补，如果他们自己往文化翻译延伸怎么办？」**
> 这恰恰是我们要抢的时间窗口。他们的核心能力在语音克隆和口型同步，不在需要长期人工审核积累的知识库资产，即使想做也要从零建。这段时间足够我们用先发优势建立数据壁垒。

## 合规/落地类

**Q13「客户的剧本、网文是版权敏感资产，你们怎么处理数据安全？」**
> 结论先行：目前无状态处理，不存储客户上传的原文，处理完即释放。（这个断言代码层面已核实成立：pipeline 无任何持久化写入，job 状态是内存态。）下一步补正式的数据处理协议，这是进企业客户前必须补齐的合规文书。

**Q14「愿不愿意把公司注册在临港新片区/滴水湖 AI 创新港？」** `[你定稿]`
> 结论先行：愿意，而且不是场面话。滴水湖 AI 创新港的「2+4+5」产业体系已经把数字文化列为 2027 年前重点培育的核心赛道之一，我们做的正是数字文化出海的最后一公里，落地在这里能直接对接短剧、网文出海企业资源。
> [你定稿：回答前确认自己真实的落地意愿边界，愿意到什么程度，别在台上承诺做不到的事。]

**Q15「天使轮 300 万、估值怎么算的？」**
> 目前更多参照同阶段（MVP 已上线 + 早期赛道验证）的天使轮估值区间，不是按 DCF 或收入倍数精算。更看重这笔钱能不能在 12 个月内做出知识库规模和真实付费客户，估值本身留有和投资人商量的空间。

## 按评委画像 + 评分表补充的高频题（这几位评委最可能问这类）

**Q16「中国文化 IP 在海外，真正的对手是韩流、日漫、Netflix，你一个审校工具怎么帮中国 IP 赢？」**（国际化视野题，评分表竞争分析明确要「其他国家同类 IP」）
> 结论先行：韩流、日漫能赢，很大程度是因为他们把「本地化」做到了极致，一集内容出海前先精细打磨文化落地；我们的内容常常输在「翻译失真」这一步，好故事被一句误译毁掉。CultureBridge 补的就是这一步，让中国文化 IP 在这场全球心智竞争里不因翻译走样而掉队。我们不直接和 Netflix 比内容，我们让每一部中国内容出海时,文化表达不掉链子。

**Q17「你怎么保证你的『文化适配』翻译就是对的？翻错了岂不是以另一种方式误导海外观众？」**（应欣辰最可能问，直击文化准确性 + 国家形象）
> 结论先行：这正是我们坚持人工审核、不让大模型自由生成的原因。每一条译法都是人工查证的纠错，不是 AI 说了算；库外拿不准的表达标注「风险待人工复核」，宁可不翻，也不硬翻。文化译错的代价我们看得很重，它损失的不只是完播率，是中华文化在海外用户心里的样子。决赛前还会引入古汉语 / 中国文化背景的顾问做二审，把准确性再抬一档。

**Q18「你提到非洲、南美这些新兴市场，它们真有付费能力吗？你怎么切入？」**（应欣辰的主场，答好加分）
> 结论先行：这些市场的价值现在不在 ARPU，在增长速度和文化距离。海外短剧下载里南美已是第二大用户区，非洲靠社交裂变快速起量。恰恰因为文化距离远、又靠社交传播，一句误译放大得最狠，文化适配在这些市场是生死线不是加分项。我们的切入点不是直接做 C 端，是服务已经在往这些市场铺内容的出海团队,帮他们把文化关。

**Q19「你的海外分发和版权合作渠道怎么建？光有工具没渠道也进不了出海方。」**（评分表营销计划 5 分明确要「海外分发与版权合作渠道」）
> 结论先行：我们不自己做分发，我们嵌进出海方已有的分发链路。第一批客户就是配音出海、字幕出海工具的现有客户,他们已经有海外发行和版权合作渠道,我们做的是他们工作流里缺的那一环文化审校。渠道策略是「借船出海」:通过和 GhostCut、配音出海这类上游工具的生态互补,直接触达他们的客户,而不是从零建渠道。
